# Concept Development

## Selection criteria

- Makes the actual handout unmistakably real.
- Works with one released resource now and more later.
- Keeps education/tools useful without becoming a directory marketplace.
- Fits the approved Missionary Media editorial system.
- Requires no new dependency or fragile interaction.

## Concept A — Field Guide Release

**Thesis:** Treat the Resources page as the release page for one real field guide, with the cover as the dominant artifact and supporting shelves beneath it.

- Structure: split featured section; guide cover on one side, purpose/contents/actions on the other; education/tools and tune-in follow below.
- Type/color: oversized ink headline, small catalog labels, warm paper, deep navy artifact stage, blue accents.
- Imagery: one project-owned cover at substantial scale.
- Motion: existing settle/reveal behavior only; restrained cover hover.
- Rejects: generic card gallery and coming-soon hero.
- Risk: page could feel too focused on one resource; mitigated by a clear `Resource 01` label and expandable shelves.

## Concept B — Resource Desk

**Thesis:** Lead with a numbered library ledger and show the selected resource in a sticky preview panel.

- Structure: left resource index, right sticky cover/detail; education/tools appear as later index categories.
- Type/color: denser catalog typography and more rules.
- Imagery: medium cover preview.
- Motion: resource-row hover changes the detail panel.
- Rejects: large hero copy.
- Risk: adds interaction and empty-library awkwardness when only one resource is live.

## Concept C — Learning Map

**Thesis:** Frame the page as two paths—learn the strategy and use the tools—with the handout bridging them.

- Structure: central guide artifact, then two equal education/tool columns connected by a visual path.
- Type/color: instructional diagram language and numbered steps.
- Imagery: smaller cover plus abstract path marks.
- Motion: path draws on entry.
- Rejects: conventional resource listings.
- Risk: the metaphor competes with the handout and adds decorative complexity.

## Decision

Select **Concept A — Field Guide Release**. The user asked to place the guide on the page and add context, and the site currently has one real resource. Concept A makes that evidence dominant, preserves the requested tune-in language, and supports later resources without pretending a library already exists.
