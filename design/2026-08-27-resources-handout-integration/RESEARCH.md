# Research Synthesis

Research scope is intentionally local and narrow: this is a revision inside an approved site direction, using one approved Missionary Media print asset. Current external destinations were checked on 2026-08-27; no third-party visual or code was imported.

## What the current site reveals

- The homepage dropdown has a strong editorial frame but weak information architecture: `About` belongs to the main navigation, generic `YouTube` duplicates more useful podcast and short-video destinations, and `Resources` still says information is coming.
- The Resources route is visually clean but currently has no resource. Its right-hand numbered ledger is a useful pattern worth retaining for tune-in links.
- The site already uses asymmetrical editorial layouts, thin rules, numbered indexes, warm paper, deep navy, and restrained blue accents. A new card-grid visual language would feel imported.

## What the handout provides

The official four-page PDF contains five useful content promises:

1. Why digital outreach can extend rather than replace traditional ministry.
2. A one-sentence audience-and-focus exercise.
3. Security considerations.
4. An eight-step, 60-day practice path.
5. A curated education-and-tools list.

The cover is the strongest evidence that a real resource exists. It should appear as the dominant artifact, not as a tiny download icon.

## User correction

The Resources experience should preserve `Tune in` and `Follow the work as it grows.` while removing About and YouTube. The supplied education channels and tools belong below the featured guide, organized by job rather than mixed into the dropdown.

## Design principles

1. **Artifact before promise.** Show the actual handout before describing future resources.
2. **One featured action.** Open/download the guide is primary; external links are secondary.
3. **A working library, not a link dump.** Separate education from tools and write one plain-language use for each.
4. **Context before brand familiarity.** A visitor should understand the guide without first reading About.
5. **Status stays honest.** The current PDF is four pages; additional resources and Spotify may still be coming.

## Anti-references

- Generic rounded SaaS resource cards.
- A creator-tools marketplace with logos and promotional claims.
- A hero that still says all resources are coming.
- Repeating YouTube as a generic destination beside podcast and Shorts links.
