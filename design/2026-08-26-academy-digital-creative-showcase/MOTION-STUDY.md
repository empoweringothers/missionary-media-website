# Motion study — Academy Digital Creative course showcase

## Decision

The course interface remains static. Motion would make a prototype interface look more operational than it is and would compete with the content inspection task.

## Existing behavior retained

- Standard anchor scrolling and existing site navigation behavior.
- Existing Academy hero image hover on pointer devices.

## Essential-content rule

No lesson, module, task, check, download, review, or capstone content begins hidden. The new page does not use the existing course-row reveal hook.

## Reduced motion

The existing reduced-motion rule removes transitions. The new interface image has no animation.
