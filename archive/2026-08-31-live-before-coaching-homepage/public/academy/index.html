The Academy lesson pattern

Short teaching. Real practice. Work that moves forward.

Each lesson follows the same clear rhythm, so the learner always knows what comes next.

Teaching block
Learn one skill or decision in a focused 5–10 minute lesson.
Guided task
Use the lesson immediately on a practical piece of ministry work.
Knowledge check
Answer a short set of questions to confirm the core idea is clear.
Download
Keep a useful guide, template, checklist, or setup card for the next time.
Repeat
Follow the same lesson rhythm until each part of the course feels familiar.
Live review
Bring the work and one question to a scheduled feedback session.
Capstone
Combine the lesson work into one final project and a clear revision plan.

Course structure

Digital Creative 101 follows one complete field-update system: purpose → plan → capture → send → learn → repeat. Each module contains a defined lesson group and ends with evidence of work completed.

  1. 01

    Purpose · Choose the communication job

    3 lessons · primary audience · supporter question · one clear result

    Module output · a one-sentence communication brief

  2. 02

    Plan · Build the field-update story

    4 lessons · three story beats · permission check · script · five-shot list

    Module output · a one-page recording plan

  3. 03

    Capture · Record usable source material

    5 lessons · phone setup · voice audio · window light · framing · b-roll

    Module output · an organized raw-media folder

  4. 04

    Send · Finish the 60-second update

    5 lessons · select · trim · caption · approve · export and post

    Module output · one captioned update ready for review

  5. 05

    Learn · Review the response

    3 lessons · replies and questions · watch-through · one improvement

    Module output · a one-page performance review

  6. 06

    Repeat · Build the next update faster

    4 lessons · file template · reuse checklist · second-update plan · live capstone

    Module output · a reviewed update and repeatable system
